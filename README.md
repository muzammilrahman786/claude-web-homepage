# AI Automation Society / Framer Clone Landing Page
A modern landing site built with React, TypeScript, Tailwind CSS, and Vite.

## Features
- Animated fluid particles background (Perlin noise canvas)
- shadcn-style UI components (Button, etc.)
- Responsive design
- Dark theme

## Tech Stack
- React 18
- TypeScript
- Tailwind CSS
- Vite
- shadcn/ui component structure

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:5173 (or the port Vite reports).

## Build

```bash
npm run build
npm run preview
```

## Deploy

Push to GitHub and connect your preferred host (Vercel, Netlify, GitHub Pages, etc.).
